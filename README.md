# Bullseye Palette Creator 2.3

Static PWA for GitHub Pages.

## Publish
1. Create a GitHub repository (for example `bullseye-palette-creator`).
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the Pages URL after deployment.

On iPhone/iPad: open the Pages URL, use Share, then **Add to Home Screen**.
